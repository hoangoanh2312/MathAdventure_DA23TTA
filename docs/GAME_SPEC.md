# MathAdventure — Game Specification

MathAdventure là game phiêu lưu giáo dục 2D top-down cho Windows PC. Người chơi điều khiển Pirate Cat khám phá năm hòn đảo, thu thập vật phẩm, tương tác với NPC, tránh bẫy, giải toán và mở kho báu.

Kiến trúc Phase 1 gồm core state/event, điều khiển Player bằng Input System, health/inventory, interaction tái sử dụng, collectibles, damage zone, camera follow và HUD hướng sự kiện. Scene test và đối tượng nền tảng được tạo/repair bằng editor tool idempotent.
